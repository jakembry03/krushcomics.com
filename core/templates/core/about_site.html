How the Site Works

krushcomics.com Domain & DNS
→
Caddy HTTPS & Reverse Proxy
→
Gunicorn Application Server
→
Django Web Application

Requests to KrushComics first reach the web server, which handles HTTPS and forwards application requests to Gunicorn. Gunicorn runs the Django application, while uploaded media and application data are stored separately from the application source code.
